# Support

For usage questions, start with the [documentation](https://generativeloaders.com/docs) and existing [issues](https://github.com/kasturibuilds/generative-loaders/issues).

If you found a reproducible defect, open a bug report and include your package version, React version, browser or runtime, a minimal reproduction, and the behavior you expected. Use a feature request for new variants or API proposals.

Please report suspected vulnerabilities privately as described in [SECURITY.md](./SECURITY.md).
